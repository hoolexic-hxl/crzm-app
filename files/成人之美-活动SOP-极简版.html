WHERE TO START

三条铁律

别的都可省，这三条不能省
01
每件事写一个名字

不写"团队"，写谁。一个人的名字 = 这件事一定会发生。

02
写死时间点

"16:00 开放签到"，不是"下午签到"。每段之间留 10 分钟缓冲。

03
开场前 5 分钟碰头

全员站一圈，把第一个小时对一遍。临门一脚，最防翻车。

THE RUN

全流程（照着勾）

13 个动作，勾完 = 一场顺的活动
活动前T-14 → T-1
  • T-14方案定稿：主题 / 时间 / 地点 / 人数上限（大型活动提前 30 天报批）
  • T-10前宣启动：海报 + 社群推送，报名信息统一收
  • T-7分工宣贯：行动计划过一遍，一人一岗定到人
  • T-1双提醒：给参与者发地址 / 交通 / 开始时间 / 取消规则；物料清点
  • T-0提前到位：场地布置完成、签到台就位
活动当天按时间点走
  • −60'志愿者到场：布置收尾 ✦ 碰头 5 分钟，过一遍第一个小时
  • −15'开放签到：签到表 + 姓名贴 + 笔，记录到场
  • 0'开场说明 3 分钟：目标 / 时间安排 / 互动边界 / 积分规则
  • 中段破冰 → 主题分享/交流 → 自由对接（每段之间留缓冲）
  • 收尾结束前 15 分钟：合影 + 反馈卡 + 预告下一场
活动后T+24h → 每周
  • T+24h后宣发布 + 积分录入（签到 / 未到 / 贡献 / 反馈）
  • T+3d复盘 15 分钟：定什么 · 出什么意外 · 下次只改一条
  • 每周检查积分榜和本 SOP，把经验沉淀进去
WHO DOES WHAT

当天分工卡

一人一岗，写在纸上贴签到台
主理人1 人

总控 + 致辞 + 现场救火。手里拿着这份 SOP。

签到1 人

名单 + 姓名贴 + 记录到场，迟到/缺席标注。

引导1–2 人

动线指引 + 主动照顾落单的人。

记录1 人

拍照片 + 记要点 + 回收反馈卡。素材当天传群里。

IF THINGS GO WRONG

应急预案

出事照做，不用开会
人数不足主理人 一对一 邀请 + 社群再推一波，提前 3 天看报名数。
物料缺现场简化：能借就借、能自制就自制（手工桌卡、纸质计分板）。
场地变提前备好第 2 个免费场地；变更 48 小时前通知参与者。
志愿者请假后备志愿者顶上；实在没人就一人多岗，砍掉最不重要的环节。
